Восстановление файла

Выберите обезличенный файл. Программа сама найдёт рядом переносимый файл восстановления и проверит, что это одна пара.

1. Выберите обезличенный файлНапример: «Файл1 — обезличенный.docx».
2. Программа подтвердит паруПара пока не выбрана.
3. Нажмите «Восстановить файл»Укажите имя и место для восстановленной копии.

Файл восстановления должен лежать рядом; его имя можно изменить — соответствие проверяется по внутреннему идентификатору пары.

Как пользоваться программой

Как обезличить документ

  1. Нажмите «Выбрать исходные файлы…» и выберите документ. Большой файл не нужно вставлять вручную.
  2. Выберите документ в «Локальной библиотеке» и дождитесь предварительного просмотра.
  3. Чтобы принимать решения вручную, выключите «Автоматически скрывать спорное без подтверждения». Затем для каждого жёлтого места нажмите «Скрыть» или «Оставить».
  4. Нажмите «Применить настройки к файлу». Программа применит ваши решения к файлу.
  5. Проверьте результат: таблицы, списки программ, имена серверов и виртуальных машин, NETBIOS, OU и контейнеры AD, названия дисков и пути.
  6. Нажмите «Сохранить два файла…». Рядом появятся «Файл1 — обезличенный» и «Файл1 — информация для восстановления.larecovery».

Как вернуть исходные значения после экспорта

  1. Положите оба файла пары в одну папку.
  2. Нажмите «Выбрать обезличенный файл…» и выберите «Файл1 — обезличенный».
  3. Программа автоматически найдёт «Файл1 — информация для восстановления.larecovery» и подтвердит совпадение по внутреннему идентификатору, а не только по имени.
  4. Нажмите «Восстановить файл…» и укажите место для результата.

Важно: файл восстановления не зашифрован и содержит исходные значения. Это переносимый JSON-формат: пару можно перенести между Windows и Linux. Передавайте файл восстановления только тому, кому разрешён доступ к исходному документу. Контрольная сумма обнаруживает повреждение файла. Неизменённый DOCX восстанавливается точно; после редактирования восстанавливаются известные маркеры, а пользовательские правки сохраняются.

Категории поиска и замены — редкая настройка

Галочка означает: искать и заменять эту категорию. Отключённые категории останутся в документе без замены.

Что искать и заменять
Секреты и ключи защищаются всегда → (удалено)

Если галочка включена, из обезличенного DOCX изображение удаляется целиком и сохраняется только в защищённой локальной карте для восстановления. Если галочка снята, рисунки остаются в документе без изменений. Текст внутри пикселей отдельно не распознаётся. SmartArt, диаграммы, OLE и графика XLSX этой функцией не обезличиваются; при обнаружении неподдерживаемого объекта экспорт блокируется и требуется ручная проверка.
