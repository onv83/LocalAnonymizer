How to use the app

How to anonymize a document

  1. In the “Source text” panel, click “Open” and select one or more documents, or drag them into the app window. The first selected document opens automatically; the others remain available under “Files and library”.
  2. Compare the “Source text” and “Anonymized text” panels. Adjust settings if needed; the preview updates automatically.
  3. Review yellow items under “Manual review of uncertain items”. Use “Hide and remember rule” or “Keep and add to exceptions”. If the queue is hidden, clear “Automatically hide uncertain items without confirmation”.
  4. In the fixed status bar, click “Apply settings to file”. Your decisions are applied to the exportable copy; the source file is not modified.
  5. Review the final document, then click “Save document and recovery file”. The app saves the anonymized document and its matching .larecovery file.

How to restore the original document

  1. Place the anonymized document and its matching file, such as “File1 — recovery information.larecovery”, in the same folder.
  2. In the “Restore a file” section at the top, click “1. Select anonymized file…”.
  3. The app finds the recovery file beside it and verifies the pair’s internal ID.
  4. After the pair is verified, click “2. Restore file…” and choose where to save the restored copy.

Important: the recovery file is not encrypted and contains the original values. It uses a portable JSON format, so the pair can be moved between Windows, Linux, and macOS. Share the recovery file only with people authorized to access the source document. A checksum detects file corruption. An unchanged DOCX is restored exactly; after editing, known markers are restored while user edits are preserved.
