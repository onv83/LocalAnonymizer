How to use the app

How to anonymize a document

  1. Click “Select source files…” and select a document. You do not need to paste a large file manually.
  2. Select the document in the “Local library” and wait for the preview.
  3. To make decisions manually, turn off “Automatically hide uncertain items without confirmation”. Then click for each yellow item “Hide” or “Keep”.
  4. Click “Apply settings to file”. The app will apply your decisions to the file.
  5. Review the result: tables, software lists, server and virtual machine names, NETBIOS, AD OUs and containers, drive names, and paths.
  6. Click “Save two files…”. “File1 — anonymized” and “File1 — recovery information.larecovery” will be saved together.

How to restore original values after export

  1. Place both files in the same folder.
  2. Click “Select anonymized file…” and select “File1 — anonymized”.
  3. The app will find “File1 — recovery information.larecovery” automatically and verify its internal pair ID, not just its name.
  4. Click “Restore file…” and choose where to save the result.

Important: the recovery file is not encrypted and contains the original values. It uses a portable JSON format, so the pair can be moved between Windows and Linux. Share the recovery file only with people authorized to access the source document. A checksum detects file corruption. An unchanged DOCX is restored exactly; after editing, known markers are restored while user edits are preserved.
