## Общие критерии приёмки

- Более точные semantic rules имеют приоритет над общими сокращениями и fallback-правилами.
- Отключение `ГОРОД`, `АДРЕС` или `УЗЕЛ` полностью отключает соответствующее новое правило.
- Ни одно правило не пересекает границы таблицы, строки или ячейки.
- DOCX-источник остаётся неизменным; обезличенный ZIP не содержит исходных значений; восстановление byte-exact.
- Source, свежий package и установленная сборка проходят одинаковые fail-closed proofs под обычным Python и `python -O`.
- Публичные tests/docs/commit metadata не содержат реальных значений из пользовательских изображений.
- GitHub Release не создаётся без отдельного разрешения.
