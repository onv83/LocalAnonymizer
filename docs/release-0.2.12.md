## Ограничения macOS

Версия macOS ARM64 предварительная. Автоматическая сборка и проверки CI прошли, но ручная приёмка на настоящем Mac по-прежнему нужна для Gatekeeper, Cmd+Enter, копирования, RU/EN, реального DOCX/Word, буфера обмена и диалогов файлов. Intel Mac, Developer ID и notarization не подтверждены.
