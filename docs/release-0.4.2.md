## Ограничения macOS

Версия macOS ARM64 остаётся **предварительной**. Автоматическая сборка и native CI
прошли, но ручная приёмка на настоящем Mac по-прежнему нужна: первый
запуск/Gatekeeper, `Cmd+Enter`, RU/EN и сохранение настроек после перезапуска,
реальный DOCX/Word, буфер обмена, диалоги файлов. Intel Mac, Developer ID и
notarization не подтверждены.
