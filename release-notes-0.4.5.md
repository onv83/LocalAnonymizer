# LocalAnonymizer 0.4.5

### Окно «Добавить правило»: исправлена геометрия

- На широком экране окно больше не выходит за пределы видимой области: высота ограничена окном приложения, список замен прокручивается внутри, кнопки «Отмена» и «Добавить правило» остаются внизу и не обрезаются.
- Размер: до 760 px по ширине и до 720 px по высоте (на узком экране — по ширине окна), поле «Что скрывать» крупнее.

### English

### “Add rule” dialog geometry fixed

- On a wide screen the dialog no longer extends past the visible area: its height is bounded by the app window, the replacement list scrolls inside it, and the Cancel / Add rule buttons stay at the bottom without being clipped.
- Size: up to 760 px wide and 720 px tall (full width on narrow screens); the “What to hide” field is larger.
