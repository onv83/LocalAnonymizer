# LocalAnonymizer 0.4.4

### Диалог «Добавить правило» стал больше

- Окно добавления правила раскрывается почти на весь блок редактирования: строка «Что скрывать» выше и крупнее, список замен занимает основную высоту и прокручивается, кнопки «Отмена» и «Добавить правило» закреплены снизу.
- Это удобнее при длинном списке категорий: видно больше вариантов сразу, не нужно ловить маленькое окно и прокручивать его целиком.

Функциональность правил, категории и формат словаря не менялись.

### English

### The “Add rule” dialog is larger

- The rule dialog now opens almost over the whole editor area: the “What to hide” field is taller and larger, the replacement list takes the main height and scrolls, and the Cancel / Add rule buttons stay pinned at the bottom.
- This is more comfortable with a long category list: more options are visible at once and the small window no longer needs to be scrolled as a whole.

Rule behaviour, categories and dictionary format are unchanged.
